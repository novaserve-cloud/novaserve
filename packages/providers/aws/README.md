# novaserve-provider-aws

> AWS Cloud deployment provider adapter for **NovaServe**.

Translates compiled Nova Intermediate Representation (Nova IR 1.0.0) graphs into AWS infrastructure resources using AWS SDK v3 (API Gateway v2, Lambda, S3, SQS, RDS PostgreSQL, EventBridge).

## Installation

```bash
npm install novaserve-provider-aws
# or
pnpm add novaserve-provider-aws
```
