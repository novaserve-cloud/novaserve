# novaserve-provider-azure

> Azure Functions and Blob Storage deployment provider for **NovaServe**.

Target adapter compiling Nova IR graphs to Microsoft Azure serverless resources.

## Installation

```bash
npm install novaserve-provider-azure
# or
pnpm add novaserve-provider-azure
```
