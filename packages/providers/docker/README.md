# novaserve-provider-docker

> Docker container builder and Docker Compose provider for **NovaServe**.

Target adapter containerizing NovaServe serverless handlers into Docker containers for local and on-premise execution.

## Installation

```bash
npm install novaserve-provider-docker
# or
pnpm add novaserve-provider-docker
```
