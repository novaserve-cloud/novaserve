# novaserve-provider-local

> In-process Hono development emulator provider for **NovaServe**.

Powers `nova dev` with an offline serverless emulator supporting hot reload, local SQS queues, file storage, and API gateway routing.

## Installation

```bash
npm install novaserve-provider-local
# or
pnpm add novaserve-provider-local
```
